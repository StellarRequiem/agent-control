# Control Stack V1 — Ambient under leash

**Pursuit:** `~/ops/CONTROL_STACK_V1_PURSUIT.md`  
**Claim:** session multi-plane control under arm/allowlist — **not** unlimited OS takeover.

## Operator day loop

```bash
# 1) Bring planes up (desktop sticky-armed; browser needs Chrome popup ARM)
python3 ~/agent-control/cli.py up
# or full preflight:
python3 ~/agent-control/grok_session.py --start-cua

# 2) Optional: Soft Reload browser-leash extension + ARM in popup

# 3) Work via host only
python3 ~/agent-control/cli.py call cua.observe
python3 ~/agent-control/cli.py call cua.step --args-json '{"tool":"desktop.apps","arguments":{}}'
# Chrome → browser.* ; other GUI → desktop.* (prefer click_window + layout)
# Full X article / status body:
python3 ~/agent-control/cli.py call browser.x_article_read --args-json '{"url":"https://x.com/…/status/…"}'

# 4) High-blast: you confirm (never invent operator_confirm=true)

# 5) End of day
python3 ~/agent-control/cli.py down
```

## Commands

| Cmd | Effect |
|-----|--------|
| `cli.py up` | Start `:8756` + `:8757`; sticky-arm desktop |
| `cli.py stack` | Ready / ambient_ready surface |
| `cli.py status` | Gated `plane.status` |
| `cli.py down` | Disarm desktop + stop owned bridge pids |
| `cli.py smoke` | cannot-bypass proof |

## Budgets (V1 defaults)

- CUA: **40 steps / 30 min** (cap still enforced)
- Hard denylist: password managers, Mail, Messages, wallets
- Post / quit / Return: human confirm

## Ambient vs authority

| Ambient feel | Still gated |
|--------------|-------------|
| One-command up | Deny-by-default pack |
| Sticky desktop arm on up | Browser ARM via extension |
| Layout in every CUA observe | Window-local clicks preferred |
| **Layout auto-refresh before click/shot steps** | Budget exhaust stops session |
| Higher work budget | High-blast still human |
| grok_session preflight | agent-soc freeze path |
